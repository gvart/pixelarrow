# EC-04 balance: class re-cost and the routed misses

`npm run balance` (200 seeds) was run on `v5` before the change (762b363) and on the EC-04 branch after it. The 13-seed round robin inside it is noisy (one cell ±14 pts), so every decision was also measured on a 40-seed round robin (same budgets 700/900, same seed scheme, 6,120 battles per run) from a throwaway harness that overrode `CLASSES[id].cost` / `mods` / `kit` at run time. Targets: STORIES.md EC-04, BASELINE.md R1 / R3 / J1, and the misses routed here by V5-037, V5-041, V5-042, V5-051, V5-056 and V5-061.

The user was asleep, so the skill prompts (balance-check Phase 1/6, the designers' option rounds) were answered here; every choice is listed under Decisions.

## Online budgets (G-ONLINE)

- **No server-rule change.** The server already validates with the shared `teamProblem` → `heroPoints` → `classPoints(CLASSES[cls].cost)`; the new costs flow through on deploy.
- **Old stored armies still validate, no migration needed:** no class costs more points than before, and only the Sacred Band changed (13 → 12). A stored team, defence snapshot or ladder ticket costs the same or less.
- **Server test** `server/test/budget.test.ts` (3 tests): every duel class is priced from its cost and costs ≤ its pre-EC-04 points (the Sacred Band is the only change); the starter roster costs the same at levels 1–10; and `/api/duel/loadout` accepts ten level-3 Sacred Band for the 150 defence budget (150 points now, 160 before) and refuses them with one at level 4 (`over_budget`). I watched the first and third tests fail with the old 125 cost.
- **Glory and gold prices.** Duel recruit Glory equals the cost: archer and slinger −3, Companion and chariot −5, royal guard −5, Sacred Band −10, militia +4. Campaign town hires move by the same amount (`cost − 40 + …`, recruits `cost − 20`); village militia stay at `RECRUIT_COST`. Real-money pricing (Stars → Drachmae) is untouched.
- Nothing is deployed. It rides train 2 (ST-04).

## Why R1 and R3 don't move with cost

Measured at 20–40 seeds per cell, royal guard vs the six shock classes:

| Lever | RG vs peltast / Gaul / falx / Celt / rhomphaia / fanatic |
| --- | --- |
| As before (130) | 0 / 0 / 0 / 25 / 0 / 0 |
| Cost 120, 115 or 110 (6 / 8 men) | 5 / 0 / 5 / 5 / 0 / 0, and RG mean 54 |
| Cost 105 (7 / 9 men) | 10 / 10 / 60 / 40 / 55 / 50, but RG mean **73** (out of band; archers, slingers, javelineers and riders at 95–100) |
| Cost 90 | mean **100** |
| +20 HP, +3 armour, +2 dmg, +30 morale, +0.15 block, steady 0.3–0.6, moraleLoss 0.5, routAt 0.1, speed +0.14, atkSpeed 0.25 | 0–35% everywhere |
| HP +200 / morale +300 | still 0 / 20 / – / – / 0 / – |
| Orb or shield wall instead of line | worse |

A trace of 7 royal guards against 14 peltasts shows the guards losing a quarter of their HP, getting flanked at 24 s, and every man routing by 30 s. With +300 morale they die 5 for 2. **Equal cost means outnumbered, and in a one-class army an outnumbered line is enveloped**, which BASELINE calls the strongest lever in the game (rear hit ×7.6 faster rout). So the cells flip from 0 to 100 when the head count crosses about 8 against 10, at cost ≈ 100. Below that the elites dominate everything, and above it they lose to every faster, more numerous class. No price or stat makes the cell 15–85% while the mean stays in band.

Militia beat cavalry because a pure-cavalry bot army charges the braced spear block head on (spears beat riders, by design). Cheaper riders (Companion at 100) still lose 90%, and +0.5 charge, morale, armour or HP change nothing. Only taking the spears away (the kit option above) or changing what the riders do moves it.

## Decisions (made while the user was asleep)

1. **Re-cost only inside each class's duel-point rounding band**, with the one exception that lowers points (Sacred Band). Stored duel teams, defence snapshots, ladder tickets and all 50 ladder floors keep their points and their battles exactly, so there is no migration and nothing for the server to learn. Bigger cuts (RG 105, Companion 124) were measured and rejected for the reasons in the tables above.
2. **No class `mods` changed.** No stat lever moved the R1 / R3 cells, and every mod change would move lairs and ladder floors for no gain.
3. **The militia kit option was rejected** (R3): it fixes the cell but breaks floors 18 and 31 by 17–29 pts, and the floor table isn't EC-04's.
4. **Archers and slingers both at 47**, not one of them. J1 needs both ≥ 40. Archer 47 with slinger 50 leaves the slinger at 39, and the reverse leaves the archer at 34. The peltast counter softens (93/80 → 65/50) as the cost. Raising the peltast to 69 didn't restore it: it made peltast vs archer / slinger 38 / 13%.
5. **The tried peltast 69, Gaul 74 and horse archer 84 were reverted.** They moved means without touching an AC (Gaul fell to 36–41%) and broke the peltast counter.
6. **Animals re-costed with the militia** (wolf 53, boar 107; bear 250 already keeps its 2 / 4 head count) so `tests/classes.test.ts` "beasts are a fair fight" and the GAMEPLAY row hold.
7. **AC 1's "against shock infantry" was read as** any cell where one of the six classes BASELINE names (Celt, rhomphaia, peltast, falx, Gaul, fanatic) beats its column by more than 85%. The report prints that list, and the table also gives the line / elite subset R1 is about.
8. **Files outside the owned list, touched minimally to keep gates green:** `tests/duel.test.ts` (the demo recruit's Glory now uses `recruitPrice('archer')` instead of the literal 50) and `scripts/duel-smoke.mjs` (expects 47).
