# AI-03 balance: ladder and war doctrines

`npm run balance` (200 matched seeds) before and after AI-03, plus ladder and war rows measured with a throwaway harness (400 seeds per row, not committed). Targets come from design/gdd/ai-doctrines.md R4.

## Existing rows: before → after

**Identical.** The two reports differ only in wall time (867 s against 1195 s, because the machine was busy). AI-03 changes only server-built setups (ladder floors, war neutrals, world bosses). The harness never builds those, so no existing row could move.

## What ships

| Source | Doctrine |
| --- | --- |
| Ladder floor `f` (not a boss) | chapter `ceil(f/10)`: 1 steady, 2 swarm, 3 rush, 4 hammer, 5 fury (`CHAPTER_DOCTRINE`) |
| Ladder boss floors 10–50 | the culture rule (`doctrineFor('mercs', culture)`): greek steady, phoenician hammer, celtic rush. Today: 10 rush, 20/30/40 steady, 50 hammer |
| War neutrals | by defender kind (`src/online/neutralDoctrine.ts`): hill tribes and pirates swarm, cultists fury, militia, outlaws, deserters, city and beasts steady |
| Lair beasts, militia, player garrisons, world bosses | steady (the default) |

## New rows (info; no GDD target)

Each row is the bot army against a steady, bot-driven mirror of itself, and shows the bot side's win rate, the median length and how often it retreated. "Before" means no doctrine, which plays steady. The mirror's side asymmetry makes steady-vs-steady land at 27–55%, so read the change between the columns, not the absolute numbers.

| Row | Before: win / median / retreats | After |
| --- | --- | --- |
| Ladder floor 5 (steady) | 52% / 58 s / 0% | 52% / 58 s / 0% |
| Ladder floor 15 (swarm) | 45% / 191 s / 0% | 51% / 134 s / 49% |
| Ladder floor 25 (rush) | 45% / 66 s / 0% | 35% / 76 s / 0% |
| Ladder floor 35 (hammer) | 35% / 270 s / 0% | 37% / 245 s / 52% |
| Ladder floor 45 (fury) | 51% / 65 s / 0% | 56% / 66 s / 0% |
| Ladder boss 10 (rush) | 29% / 133 s / 0% | **15%** / 98 s / 0% |
| Ladder boss 20 / 30 / 40 (steady) | 54% / 52% / 48% | unchanged |
| Ladder boss 50 (hammer) | 55% / 154 s / 0% | 56% / 163 s / 36% |
| War neutrals, tier 3: tribes (swarm) | 48% / 71 s / 0% | 43% / 45 s / 54% |
| War neutrals, tier 3: pirates (swarm) | 27% / 79 s / 0% | 34% / 63 s / 66% |
| War neutrals, tier 3: cultists (fury) | 47% / 45 s / 0% | 48% / 36 s / 0% |

Readings:

- Floor strength stays within about ±10 points, except for **boss 10**. A rush wedge of garrison hoplites drops its shield wall, which makes the first boss easier (29% → 15% against its mirror). This is the GDD's culture rule as written, so it is kept, and the row is flagged for the ST-04 balance pass.
- swarm and hammer floors retreat in about half of their battles. On the ladder a retreat is a player win, so those floors end sooner (191 → 134 s on floor 15). Nothing forces `retreatAt` to 0 for ladder bosses, because ai.ts is not this story's file. Boss 50 (hammer) retreats 36% of the time.

## Compatibility

- Doctrines are derived from the floor or region and never stored. Ladder floors, regions and boss rows need no migration.
- Tickets store their setup. A ticket issued before AI-03 has no doctrine field and replays as steady, and an in-flight v1 ticket still verifies with the frozen v1 sim, which ignores the field (server/test/neutrals.test.ts).
- The async defence doctrine picker is not built. It is already in the plan's cut list (SPRINTS.md "Cut list", ANSWERS A-37).
- No doctrine prefers the orb (V5-041), and a test checks this.
