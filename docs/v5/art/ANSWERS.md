## /create-game-assets

| Step | Answer |
| --- | --- |
| 1. Inspect before inventing | Inspected the v4 mockups, `public/ui` (2 placeholder JPEGs), `public/icons` (2 painted atlases), procedural art in `src/art`, the font pipeline, and the render scale. The v4 direction is kept: parchment, meander, terracotta. |
| 2. Lock the technical frame | Phaser 3.90 WebGL; portrait 390x844 reference; UI px = S device px (2–6 on phones); painted rasters cover-cropped by `coverTexture`; LINEAR filter for painted art, NEAREST for pixel art. Recorded in art bible §8.1. |
| 3. Name the visual system | Art bible §1–4 and §7. |
| 4. Asset manifest | `docs/v5/art/asset-manifest.json` (56 entries), the twin of `ASSET_LIST.md`, generated by `scripts/art/list.mjs`. |
| 5. Approve one visual target | Delegated choice: each family's **seed** is named (bust_hoplite, plate_hydra, fresco_campaign, icon_book). The rest of the family is generated with the approved seed attached. |
| 6. Families | The templates share the T-STYLE block, and variants are edits of their base. |
| 7. Normalize deterministically | `process.mjs` (key, trim, exact resize, palette snap) and `check.mjs` (raster QA). The bundled Python scripts need Pillow, which is not installed here. I did not install packages: the same checks are in Node with no dependencies. |
| 8. Engine import settings | §8.6 rules: NEAREST and integer device scale for pixel art; LINEAR, downscale only and a mip chain for painted art. Atlas in TexturePacker hash format. |
| 9. Validate in context | `preview.mjs`: the real game, real fixtures, 3 sizes, DPR 3 shots. |
| 10. Provenance | Raw files stay in `docs/v5/gemini/` (named by ART-id and attempt), and ASSET_LOG Done records raw → staged → shipped. |

## Brief-level choices

| Question | Answer |
| --- | --- |
| Font | Keep Cinzel (caps only) plus Inter; propose Inter 600 for names and titles. Measured that the word splits are not a metrics problem (OI-1). |
| Web font or bitmap? | Both: bundled web font, rasterized once into BitmapFont atlases at device density, after `document.fonts.check`. |
| Grey buttons | Grey = disabled only. Disabled = flat, no rim or shadow, plus a reason or lock. Every enabled non-primary action is bronze. |
| Chrome raster or procedural? | Procedural (the v4 decision kept). The 9-slice pipeline exists for later raster chrome. |
| Pixel world sizes | Measured ones cited; 48, 96 and 160x128 tiers decided for new art. |
| Tools language | Node, no dependencies (no Pillow, sharp or ImageMagick on this machine), plus macOS `sips` for JPEG. |

## Decisions for the Director to log (DECISIONS.md)

| ID | Decision | Alternatives | Why |
| --- | --- | --- | --- |
| D-1 | Menu art is painted (fresco style) and world art is pixel art. Pixel art appears in menus only in "world windows" (niches, encounter, map), at an integer **device-px** scale. | Allow pixel crops as portraits | Audit G8 and RES-1 (the headless MVP). |
| D-2 | Cinzel is all caps only, at 7 UI px or more. Mixed-case names and titles go in Inter; add Inter 600. The bitmap-atlas word-split bug (OI-1) becomes a UI tech story with a 5-word regression test. | Replace Cinzel; Phaser Text per string | Caps Cinzel renders clean in the same pipeline today, and the metrics were measured correct. |
| D-3 | Grey = disabled only. Disabled = flat (no bevel, rim or shadow) plus a reason line or lock. Every enabled non-primary action is bronze. Lint the `neutral` variant on enabled buttons. | Keep grey for neutral | Audit G2. |
| D-4 | 21 painted **class busts** replace the per-hero rendered portraits in every menu well. The battle HUD keeps the rendered faces. | Per-hero painted portraits (unbounded); keep the rendered faces (G8) | A bounded set (21) that reads at 21 UI px. Per-hero variety is lost in menus: the owner may veto. |
| D-5 | Painted art ships at slot x 6 (3x phones), only downscaled, with a mip chain in `coverTexture` when the ratio is above 2. The splash ships at x2 CSS. Busts and plates load per scene, not in Boot. | x12 masters | Telegram load size. |
| D-6 | Battle group colours move to ochre, olive, slate-teal and plum (no red group I), menus and battle alike. | Keep red I | Audit G3. Red is reserved for alerts. |
| D-7 | Settlement vignettes are kind x culture (6). The lair is excluded (never shown). | Kind x coastal | Culture is real data and is invisible today. |
| D-8 | Chrome stays procedural. Raster 9-slice is only for a later explicit decision. | Gemini raster chrome (V4 brief section B) | Sharp at every density; states come from tokens. |
| D-9 | No asset reaches `public/` without `scripts/art/preview.mjs` (real game, 3 sizes) and `promote.mjs --looked`. | Manual copy | The brief's "check against the real game before saving". |
| D-10 | New icons are 160 px cells; the 101 legacy 64 px icons are regenerated in a later batch (OI-3). | Keep 64 px | They blur on 3x phones above 10 UI px. |
