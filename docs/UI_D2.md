# UI "Bronze & Stone" (D2)

The UI layer's look since the D2 redesign: **the game world stays pixel art;
everything you read or tap is smooth, vector and mixed case.** Dark stone
panels with a fine bronze rim, bevelled bronze buttons, **one terracotta
button per screen** (the next thing to do), a lit bronze state for "the one
you picked", light text, Inter for reading and Cormorant SC for names and
headings. The screen structure of docs/UI_STRATEGOS.md (sentence on top, one
action, numbers with words) is unchanged; this page is how it is drawn.

The concept study (four directions, then three softer takes on the chosen
one) lived outside the repo; D2 was picked for its "serious strategy game"
feel: materials instead of candy colours.

## Rendering: why it is sharp

| Piece | Where | What it does |
| --- | --- | --- |
| Render scale `RS` | `src/platform/renderScale.ts` | The canvas is drawn at device pixels (CSS px x RS, RS = devicePixelRatio, capped at 3). `scene.scale.width`, pointer coordinates and `getBounds()` are device px. |
| UI scale `S` | `uiMetrics` in `src/ui/kit.ts` | Whole UI px per CSS px (2..4) **times RS**, so layouts in UI px did not change. |
| World cameras | Battle, World | Zoom in "zoom units" (`camZoom(z)` / `zoomUnits(zoom)`), i.e. the old 1x = `RS`. |
| Raw pixel thresholds | drag/tap slop, grab radii | Given in CSS px and multiplied by RS (`px()` or `* RS`). |
| Layout check | `src/ui/layout.ts` | Reports CSS px (it divides by RS), so its rules and scripts are unchanged. |

Scripts that turn `getBounds()` or a camera projection into a tap must divide
by RS (the canvas rect width over `game.scale.width`).

## Type

`src/art/vectorFont.ts` draws the faces into the same Phaser bitmap-font
atlases the kit always used, at the screen's density, so every `addText` /
BitmapText renders smooth type with no call-site change.

| Face | Use | Font key |
| --- | --- | --- |
| Inter 500, 8 UI px em at the base size 7 | everything you read | `ink`, `dim`, `light`, `gold`, `red`, `good`, `title`, rarity fonts |
| Cormorant SC 700, 10 UI px em | names and section headings ("ORDERS · PHALANX I", group names, the wordmark) | `head` |

- `measureText(str, shadow, size, face)` (src/ui/textfit.ts) measures from
  `src/art/fontMetrics.ts`, generated by `node scripts/font-metrics.mjs` from
  the bundled `@fontsource` files. Re-run it after changing a face or weight.
- Sizes: 7 (base, 16 CSS px at S = 2) for body text, 6 for words under an
  icon and small buttons (`small: true`), 5-5.5 for plates and captions.
- Both faces cover Russian. A character with no metrics measures as missing
  (`missingGlyphs`).

## Surfaces

`src/art/smoothUi.ts` draws every kit panel style with Canvas 2D at the
screen's density; `panelTexture` caches them and `panelImage` shows one scaled
to UI px (an image of a panel texture is scaled by `1 / panelK`: keep that
scale when swapping its texture).

| Style | Look | Use |
| --- | --- | --- |
| `parch`, `scroll` | stone gradient `#2f261e -> #1a1511`, bronze rim `#8c6a3c` | panels, sheets, bars |
| `dark`, `tooltip` | deeper stone, bronze rim | tips, hint pill, banners, plates |
| `inset`, `slot`, `tab` | stone well, faint bronze rim | wells, cards, unselected tabs |
| `slotSel` | lit bronze rim | the selected card or slot |
| `button` | bronze bevel `#8a6a40 -> #503a21`, a 2 px lip | every secondary action |
| `buttonSel` | terracotta `#c2563a -> #76291a` | **the** primary action (`variant: 'primary'`) |
| `buttonOn`, `tabSel` | lit bronze | selected toggle / tab / the order in force (`style: 'buttonSel'` on a kit Button) |
| `buttonDanger` | quiet stone | destructive (confirm first) |
| `buttonOff` | flat dark stone | cannot, with a reason |

Colours (also exported from smoothUi.ts): text `#f1e8d8` / `#c2b49c` /
`#8f826d`, bronze `#e2c48c` / `#b48a52` / `#8c6a3c` / `#5c4325`, terracotta
`#c2563a` / `#a3402a` / `#76291a`, health `#b4483a`, morale `#7a93a6`, good
`#a8bf7a`, gold `#d8b36a`.

## Battle HUD (`src/ui/battleHud.ts`, `BattleScene.buildHud`)

- **Top bar** (`TopBar`, 46 UI px): Pause / Play (terracotta while paused),
  speed (`2×`, lit when fast), the clock with its word, Flee; under them the
  two armies' strength, "You 86% [bar] vs [bar] 92% Foe". In deployment:
  Leave, the men count, Men; online deployment shows the seconds left and a
  draining bar.
- **Hint pill** (`HintPill`): the situation sentence under the top bar. A
  banner (first contact, a terrain tip) takes its place while shown.
- **Ability medallions** (`Medallion`) down the field's right edge: name and
  what it does on a plate, a gold halo when ready, a sweep and the seconds
  while recovering, a count bubble for several ready holders. Same
  `setBlocked` / `setCorner` API as the kit Chip, plus `setCooldown(f)`.
- **Bottom sheet**: group cards two per row (`GroupCard` wide layout: numeral
  disc, name, "7 men · advancing", health and morale bars), a header line
  ("ORDERS · PHALANX I" and the Formation chip, Reset / Alone / Rejoin), then
  the five orders as labelled buttons (the order in force lit) or, in
  deployment, a full-width Fight / Ready.
- The radial ring round the group is no longer built (its order list,
  `ringOrders()`, feeds the order row). The tutorial lights the same keys
  (`cmdBtns`: advance, charge, hold, loose, fallback, abilities; `tabBtns`:
  formation, abilities).
